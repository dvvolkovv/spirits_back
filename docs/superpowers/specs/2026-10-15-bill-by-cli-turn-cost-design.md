# Списание хода веб-чата по счёту CLI — дизайн

**Дата:** 2026-10-15
**Статус:** дизайн согласован владельцем
**Репозиторий:** `spirits_back`

## Задача

Ход веб-чата через релей (обычный и с файлами) списывается в `ChatService.computeSdkCharge` как `max(формула из usage, стоимость хода от CLI)`. Формула переводит взвешенный usage в доллары по цене Opus 5 — `SDK_INPUT_USD_PER_MTOK = 5` ($5 за миллион входных). С 23.09.2026 веб-чат закреплён на `claude-opus-5-5`, и CLI (который знает её цену: `hasUnknownModelCost=false` в `cost-state`) насчитывает за ту же работу меньше — $3,0–4,6 за миллион «входных» единиц. Первый алерт роста стоимости 15.10 показал ход: формула $2.70, CLI $1.66 (×1,63). Из-за `max()` пользователь платит по формуле — на 10–65% больше счёта CLI.

## Решение владельца (15.10.2026)

- Списывать по счёту CLI за ход (`turnCostUsd`, который релей присылает в `done`: итог CLI минус `cost-state` прошлого хода; в нём основная модель по её цене, субагенты, Haiku внутри WebSearch/WebFetch, веб-поиск). Формула из usage — запасной путь, если релей стоимость хода не прислал.
- Страховка снизу: не меньше 0,15 формулы (`SDK_TURN_COST_FLOOR=0.15` в `.env`) — защита от ошибки релея в вычитании `cost-state` (14.10 там же была поломка в обратную сторону). Сначала владелец выбрал 0,5; прогон по логу прода показал, что 0,5 срабатывает на всех ходах Haiku (честное отношение 0,20) и задевает ходы opus-5-5 (0,49), — решение 15.10: 0,15. Сработала страховка — это видно в раскладе хода (`взято=пол`).

## Правило

`computeSdkCharge(usage, costUsd, text, turnCostUsd)`:
1. usage есть:
   - `usageUsd = implied + поиски` (как сейчас);
   - `turnCostUsd > 0` → `billable = max(turnCostUsd, FLOOR × usageUsd)`; расклад `взято=ход` или `взято=пол` (сработала страховка);
   - иначе → `billable = usageUsd`, `взято=usage`.
2. usage нет, `turnCostUsd > 0` → по стоимости хода (как сейчас).
3. дальше — без изменений (`costUsd` сессии, длина текста, проброс ошибки апстрима).

`SDK_TURN_COST_FLOOR` — из `.env`, по умолчанию 0,15; бессмысленное значение (не число, ≤ 0, > 1) — 0,15. Курс `SEAT_TOKENS_PER_USD` не меняется.

Не меняется: TG-боты и Маша (уже списывают по счёту CLI), индикатор в событии `end` (считается тем же `computeSdkCharge`), алерты «Дорогой ход» и рост стоимости (получают итоговое списание).

## Проверки

- Тесты `computeSdkCharge`: CLI дешевле формулы → взят CLI; CLI ниже половины формулы → пол; CLI дороже формулы (субагенты, поиски) → CLI; стоимости хода нет → формула; `SDK_TURN_COST_FLOOR` из окружения и мусор; индикатор и списание совпадают (существующие тесты).
- **Прогон по логам прода** (только чтение): строки `billing[usage]` / `billing[upload:usage]` с `implied=… ход=…` с 14.10 — сколько ходов, распределение `ход / формула`, на сколько изменятся списания в сумме, сколько ходов упрётся в страховку.
- После выката — одна строка `billing[...]` живого хода в логе прода с `взято=ход`.
