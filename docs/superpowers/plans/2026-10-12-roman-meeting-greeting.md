# Приветствие Романа и рассказ о себе — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сократить первую фразу ассистента на встрече до приветствия и предупреждения о записи, а развёрнутый рассказ о себе отдать в ответ на прямой вопрос.

**Architecture:** Обе фразы живут в `voice-host/src/prompts.ts` и больше нигде. `meetingIntro()` — скрипт на произнесение, отдаётся модели сразу после входа; `meetingInstructions()` — правила поведения, лежат в системном промпте всю встречу. Правило обращения переезжает из первой во вторую. Воркер `agent.ts` только передаёт данные: из него уходит один аргумент и добавляется одно поле.

**Tech Stack:** TypeScript, Node.js, `node:test` через `tsx --test`, LiveKit Agents 1.7.0.

**Основа:** [2026-10-12-roman-meeting-presence-design.md](../specs/2026-10-12-roman-meeting-presence-design.md), пункты 1–2. Пункты 3 (триггер режима слушателя) и 4 (микрофон) — отдельными планами.

---

## Порядок задач и почему он такой

Сначала блок «о себе» (Task 1), потом сокращение приветствия (Task 2). В обратном порядке между коммитами возникает окно, где правило обращения не звучит нигде: из входа уже убрали, в инструкции ещё не положили.

Task 3 правит воркер. До него проект не собирается — `meetingIntro()` теряет второй параметр, а вызов в `agent.ts` его ещё передаёт. Это ожидаемо и ловится `tsc`.

```typescript
/**
 * Рассказ о себе — по прямому вопросу, а не во вступлении.
 *
 * Раньше ассистент выкладывал всё на входе: кто он, чей он, как к нему
 * обращаться. На чужой встрече это полминуты служебного текста до того, как
 * люди успели поздороваться. Решение владельца 12.10.2026: на входе — только
 * приветствие и запись, подробности — когда спросят.
 */
describe('рассказ о себе', () => {
  test('по вопросу отвечает коротко и называет, чей он ассистент', () => {
    const s = flat(meetingInstructions({
      name: 'Роман', persona: '', preamble: '', specialists: SPECIALISTS,
      ownerName: 'Дмитрий',
    }));
    assert.match(s, /Спросили, кто ты/);
    assert.match(s, /ассистент Дмитрий/);
    assert.match(s, /двумя-тремя фразами/);
  });

  test('без имени владельца подставляется заглушка', () => {
    // «Ассистент пользователя» на внешней встрече звучит как строка из лога.
    const s = flat(meetingInstructions({
      name: 'Роман', persona: '', preamble: '', specialists: SPECIALISTS,
    }));
    assert.match(s, /ассистент владельца встречи/);
    assert.doesNotMatch(s, /ассистент пользователя/);
  });

  test('формула «пока слушай» переехала сюда из вступления', () => {
    // Это единственный способ заткнуть ассистента. Из вступления она ушла,
    // значит обязана звучать хотя бы в ответе на прямой вопрос.
    const s = flat(meetingInstructions({
      name: 'Роман', persona: '', preamble: '', specialists: SPECIALISTS,
    }));
    assert.match(s, /«Роман, пока слушай»/);
    assert.match(s, /назвать по имени/);
  });

  test('сам, без вопроса, о себе не рассказывает', () => {
    // Без явного запрета «расскажи, когда спросят» читается как разрешение
    // рассказать — и модель выкладывает возможности в первом же ответе.
    const s = flat(meetingInstructions({
      name: 'Роман', persona: '', preamble: '', specialists: SPECIALISTS,
    }));
    assert.match(s, /САМ, пока не спросили/);
    assert.match(s, /ни во вступлении, ни в первом ответе/);
  });
});
```

```typescript
/**
 * Первая фраза на встрече — приветствие и предупреждение о записи.
 *
 * Единственное исключение из молчания: произносится сразу после подключения,
 * до всякого обращения.
 *
 * Правило обращения отсюда УБРАНО (решение владельца 12.10.2026, отменяет
 * решение 26.08.2026). Оно занимало половину вступления, а нужды в нём нет:
 *   • гейт открывается на одно ИМЯ — «Роман» сам по себе законный вызов
 *     (addressedByName в name-gate.ts), формула «вопрос к тебе» необязательна;
 *   • формулу возврата произносит listenAck() — то есть ровно в тот момент,
 *     когда ассистента увели в молчание и она кому-то понадобилась;
 *   • полный ответ про себя и про обе команды остался в meetingInstructions()
 *     и звучит по прямому вопросу.
 *
 * Имя владельца тоже убрано: на внешней встрече люди видят его в списке
 * участников — «Роман · ассистент Дмитрия» (assistant-signature.ts).
 *
 * Запреты перечислены явно и поимённо. Persona и список специалистов лежат в
 * том же системном промпте, и на короткое «представься» модель охотно
 * пересказывает их целиком — ровно та многословность, от которой уходим.
 */
export function meetingIntro(name: string): string {
  return (
    'Ты только что вошёл во встречу. Скажи ПО-РУССКИ ОДНУ короткую фразу и замолчи: ' +
    `поздоровайся, назовись — ${name}, — и скажи, что встреча записывается. ` +
    'Ни одного английского слова. Не рассказывай, кто ты и что умеешь, ' +
    'не объясняй, как к тебе обращаться, не задавай вопросов и не перечисляй списков.'
  );
}
```
