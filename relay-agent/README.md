# relay-agent — AI-relay ассистентов (r.linkeon.io)

Код лежит здесь, **а работает на другом сервере**: `5.101.115.184`
(`r.linkeon.io`), каталог `/home/dv/file-agent`, под PM2 процессом
`file-agent`.

## Что это

Через него отвечают все ассистенты Linkeon, кроме Маши. Прод-бэк ходит
сюда за ответом: `AGENT_URL` в `src/chat/chat.service.ts` и
`src/chat/chat.controller.ts`, по умолчанию `https://r.linkeon.io`.

На каждый запрос `server.mjs` поднимает **Claude Code CLI**
(`claude --print --output-format stream-json`) и стримит ответ обратно
NDJSON-ом. Отсюда же берутся файлы, которые ассистент создал за сессию.

## Почему код появился в репозитории только сейчас

Каталог заводили как времянку, а он стал боевым: правился прямо на
сервере, и единственной защитой был ручной бэкап перед каждой правкой.
К моменту переноса рядом с `server.mjs` лежало **27 файлов вида
`.bak*`** — по ним не видно ни что менялось, ни зачем, и откат
превращался в гадание по датам.

## Как файлы попадают пользователю

Всё, что ассистент кладёт в `/tmp/agent-output/<ключ папки>/`, уезжает в
событии `done` списком `outputFiles`, а бэк превращает его в ссылки вида
`https://r.linkeon.io/files/<ключ папки>/<имя>`. Ключ папки — `fs_key` от
бэка (32 hex от HMAC ключа сессии, без номера телефона; `paths.mjs`,
`turnFsKey`), у ходов без него — санитизированный `sessionId`, как до
26.10.2026. Загрузки называются `<ключ папки>_<имя>`.

Отдаётся то, что создано или изменено **за этот ход** (сверка со снимком
папки на его старте). С 06.08 по 11.08.2026 отдавалась вся папка с
признаком `fresh` у каждого файла; `bac27cb` вернул «только новое» —
эта заметка тогда не обновилась.

Плюс файлы прошлых ходов той же сессии, чей `done` до бэкенда не дошёл
(`undelivered-files.mjs`). Бэкенд мог уйти раньше конца хода — рестарт
API при выкате, обрыв связи: claude доделывает ход и кладёт файлы на
диск, но список в `done` писать некому. 20.10.2026 так пропала справка:
на «что молчишь?» ассистент ответил «файл прикреплён ниже», а ссылки не
было. Теперь такие файлы откладываются (в памяти, до 7 дней; рестарт
релея их забывает) и уходят со следующим ходом сессии, если ещё лежат
на диске.

## Чего здесь нет

- `.env` — там `GEMINI_API_KEY`, в репозиторий не берём;
- секретов MCP. Базовый `empty-mcp.json` пуст (`{"mcpServers": {}}`):
  сервер `linkeon` подключается в конфиг хода из `linkeon_token` бэка
  (`linkeon-mcp.mjs`), как `products` и `talerid`. До 26.10.2026 боевой
  файл держал общий `MCP_SECRET` прода; с 06.08 по 07.10.2026 он лежал
  тут целиком. На релее файл по-прежнему вне git; вернуть сюда сервер или
  секрет не даст `src/mcp/relay-mcp-template.spec.ts`;
- `node_modules` — 69 МБ, ставятся из `package-lock.json`;
- аккаунт Claude Code — он в `/home/dv/.claude/` на сервере, вход по
  подписке. Тем же аккаунтом на той же машине пользуются посторонние
  задачи: `spirit/run.sh` в кроне, `smilebot-agent`, мониторинг Taler —
  смена учётки заденет их все разом.

## Правка

Сейчас рабочий каталог на сервере — самостоятельный git-репозиторий с
собственной историей. Пока правки идут там, сюда их надо переносить
руками. Правильнее развернуть на сервере рабочую копию из этого
репозитория (sparse-checkout по `relay-agent/`), тогда путь станет
обычным: коммит → push → `git pull` на сервере → `pm2 restart file-agent`.

## Секрет бэка (`X-Agent-Secret`)

Релей проверяет все пути, кроме `/health` и `/files/*` (и `OPTIONS`-preflight) — заголовок `X-Agent-Secret` должен совпасть с одной из строк файла `relay-secrets` (рядом с `server.mjs`, права 600, не в git; путь переопределяется переменной `RELAY_SECRETS_FILE`). Режим — файл `relay-auth-mode` (путь — `RELAY_AUTH_MODE_FILE`): `log` (пропускать и писать «отказ был бы») или `enforce` (401). Оба файла перечитываются раз в 30 с, рестарт не нужен.

Файлы переписывать атомарно — во временный файл рядом и `mv` на место, а не редактировать существующий: `mv` на той же файловой системе — одна операция, читающий процесс не увидит файл наполовину записанным.

Смена секрета без простоя: добавить новую строку в `relay-secrets` → заменить `RELAY_SECRET` в `.env` бэка → `pm2 restart linkeon-api` при нуле живых ходов → удалить старую строку. Значения не печатать: передавать трубой `ssh … | ssh …`.
